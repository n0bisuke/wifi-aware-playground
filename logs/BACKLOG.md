## 確認したいこと

- [ ] **Wi-Fiルーターなしでの通信:** 機内モードでWi-Fiだけオンにし、どのネットワークにも接続しない状態で試す。今回の目標の最後の確認。
- [ ] **ルーターなしでのペアリング:** 同じ状態でペアリングからやり直す。

- [ ] **数分で切れる原因:** 切断対策を残す場合は、10分ほどつなぎ、画面の「前回:」の内容を確認する。

## 機能の候補

- [ ] **動画や大きなファイルの転送:** ファイルを分割して送り、進捗バー、MB/s、残り時間を表示する。受信後に再生する。今の写真送信は全体をメモリに読み込むので、別の作りが必要。接続の安定を先に確認するのがおすすめ。
- [ ] **複数台からの写真集め:** iPhoneまたはiPadをホストにして、複数のJoinから写真を集める。今は最新の1台だけを相手にする作りなので、複数接続への変更が必要。試すには3台以上あると確実。
- [ ] **Pingの測定:** 往復の遅延をmsで表示する。
- [ ] **`bulk` と `realtime` の切り替え:** 速度重視と遅延重視の違いを見比べる。お絵描きの遅れが気になる場合にも役立つ。

## ほかの機器との接続

- [ ] **ESP32とiPhoneの接続:** M5Stamp C5(ESP32-C5)を用意し、ESP-IDF v6.1以降で試す。まずEspressifの `udp_server` の例で接続を確認し、その後AwareChatからの接続を検討する。
  - 参考: [ESP-IDFのWi-Fi Awareドキュメント(ESP32-C5)](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c5/api-reference/network/esp_nan.html)。iPhoneとペアリングの記載はない。
  - AtomS3(ESP32-S3)は対応チップに入っていないので使えない。
  - 手元の無印ESP32で試す案もあるが、iPhoneとつながるかは未確認。
- [ ] **Androidとの接続:** 動作例は見つかっていない。実機があれば試す価値はあるが、成功を前提にしない。
- [ ] **Macを受け皿にする構成:** Wi-Fi AwareはmacOSに非対応なので、別の仕組みが必要。Networkフレームワークのピアツーピア接続か、同じLANのサーバーになる。

## 環境の改善

- [ ] **Wi-Fi経由のインストール:** Finderで「Wi-Fi接続時にこのiPhoneを表示」を設定しても、`usbmuxd` の一覧には出なかった。`xcrun devicectl` でMacから入れる方法は未検証。
- [ ] **距離の測定:** Wi-Fi Awareでは測れない。正確に測るなら、Nearby Interaction(UWB)を使い、トークンの交換にWi-Fi Awareの接続を使う案がある。
- [ ] **Macアプリ開発の検証:** コンテナではMach-Oの生成までで、`swift build` は `codesign` がなく失敗した。実行、梱包、署名、公証は未検証。Mac側のツールとの組み合わせが必要になる見込み。
- [ ] **ライセンスの追加:** 他の人に再利用してもらうなら追加する。
- [ ] **`Dockerfile` のバージョン固定:** xtoolは `latest` を取得するので、再現性のために固定を検討する。
